# INI++ Unicode Edition
A Unicode port of Jax's INI++ Extension that includes extra features than the classic INI extension. Unlike the original version, that is Non-Unicode and uses ANSI Encoding, INI++ Unicode supports Unicode *(like the name says)*, but some features might be missing or broken
# What is an INI File?
An INI file is mostly used to save progress, configuration, or store other information. Each file stores multiple groups that have items inside them *(Values and Strings)*.
Example of an INI File:
- [Progress]
- Coins=100
- Goals=5
- SuperKick=1
- [Config]
- Fullscreen=1
- VSync=1
- Anti-Aliasing=1
# Features
- Custom-Algorithm Encryption - Make your INI file extra protected!
- Compression - Reduce the file size of your INI!
- Merging - Merge Groups and other INIs!
- Subgroups - Groups with subgroups can be simulated with the object!
- Hashed Strings - Hash Strings via MD5 to protect passwords and other strings!
- No Limits - Unlike the classic INI object, which limits the file size to 64 KBs *(Only works on Windows 9x)* and item text cannot exceed 1024 characters, INI++ does not have these limits!
- And more...
# Negative Aspects
- Comments - INI++ does not support comments. No matter what, they will always get removed.
- Ordering of Items and Groups - The current ordering in INI++ is Alphabetical
- Blank lines, spaces, etc.
# Unicode Port Limitations
Like mentioned, the Unicode Port still lacks some features that are avaliable in the non-unicode port, such as:
- Advanced Debugging Features
- And more...
